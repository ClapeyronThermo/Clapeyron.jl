Potential models

A potential model is an EoS model that represents the shape of the residual Helmholtz surface of an intermolecular potential, expressed in reduced (natural) units rather than physical ones. In particular terms of the Clapeyron implementation:

  • T_scale(model,z) = 1
  • Rgas(model) = 1

A potential model can be coupled with a (molecular) scaling model in a corresponding states framework to act directly as a provider of real thermodynamic properties, or may be the building block of a more complex EoS.

Corresponding states models

Corresponding states models inheriting the CorrespondingStatesModel in Clapeyron use the following API:

scaling = Clapeyron.scaling_model(model::CorrespondingStatesModel) #get inner scaling model
reference = Clapeyron.reference_model(model::CorrespondingStatesModel) #get inner reference model
f,h = Clapeyron.shape_factors(scaling::MyScalingModel,reference,T,z) #get temperature and volume scaling factors, as a method of the scaling model and the scaled temperature.
f,h = Clapeyron.inverse_shape_factors(scaling::MyScalingModel,reference,T,z) #instead of the scaled temperature, the reference temperature is used as input.

Clapeyron provides specialized methods that reroute the evaluation of some properties to the reference model first, and then perform the scaling, instead of creating shape factors multiple times.

Corresponding states API

Clapeyron.CorrespondingStatesModel — Type

abstract type CorrespondingStatesModel <: EoSModel end

Abstract type containing corresponding states (CS) models. corresponding states models are defined as:

Aʳᵉˢ(T,v,x)/RT = Aʳᵉˢ₀(T₀,v₀)/R₀T₀        T₀ = T/f ,  v₀ = v/h

In particular, the code implementation is just two methods.

function a_res(model::CorrespondingStatesModel,V,T,z)
    reference = reference_model(model)
    scaling = scaling_model(model)
    return a_res_ecs(reference,scaling,V,T,z)
end

function a_res_ecs(refmodel,scalingmodel,V,T,z)
    f,h = shape_factors(scalingmodel,refmodel,T,z)
    T0 = T/f
    V0 = V/h
    return a_res(refmodel,V0,T0,z)
end

The following functions are required:

  • reference_model : provides a single-component, helmholtz equation of state, used as reference for the shape their a_res V-T surface.
  • scaling_model : provides a struct that defines the scaling between the real fluid and the reference fluid.
  • shape_factors : the scaling model needs to define f,h = shape_factors(scaling::MyModel,reference,T,z).

Some reference models may carry its own scaling (or no scaling at all). For those cases, you may need to overload a_res_ecs

Clapeyron.SPUNGScaling — Type
SPUNGScaling(components, reference_component, model, refmodel;
shape_userlocations = nothing,
shaperef_userlocations = nothing,
verbose = false)

SPUNGScaling(shape_model, shaperef_model)

Input models

  • model: cubic equation of state that describes the fluid (or mixture) of interest, the shape equation (for example SRK or PR). A cubic built beforehand can also be passed; it is then used as it is.
  • refmodel: cubic equation of state that represents the reference fluid. It must be the same equation as model: same functional form, same α(T) function and same mixing and translation options. Only the substance, and the parameters describing it, may differ (see the notes below).

Input parameters

  • components: substances of the fluid or mixture of interest.
  • reference_component: the reference substance, as named in the cubic-equation database.
  • shape_userlocations: alternative parameter source (files or values) for the cubic of the fluid of interest. Replaces database critical constants, acentric factors or binary interaction parameters, and therefore changes the scale factors.
  • shaperef_userlocations: the same, for the cubic of the reference fluid.
  • verbose: prints information about the parameters used while the model is built. It does not change any result.

Description

Scaling model of the SPUNG equation of state, to be used with ECS. Its role is to say which state of the reference fluid corresponds to a given state of the fluid of interest: a state (T, v, x) is mapped to the reference state

T₀ = T/f
v₀ = v/h

where f and h are the temperature and volume scale factors. They are obtained from the cubic equation of state, written as

P = RT/(v-b) - a(T)/((v+δ₁b)(v+δ₂b))

Two states are considered corresponding when the two dimensionless groups of the cubic coincide,

Γ = a(T)/(b·R·T)       β = b/v

For a cubic these two groups fully determine the reduced residual Helmholtz energy, so equality of Γ and β means equal reduced residual Helmholtz energy. This gives

h = v/v₀ = b/b₀
f = T/T₀ = [a(T)/b] / [a₀(T₀)/b₀]

where a, b belong to the fluid of interest and a₀, b₀ to the reference fluid, both from the same cubic equation. f appears on both sides (T₀ = T/f), so it is the solution of an implicit equation. For pure fluids described by Soave-type α(T) functions (SRK, PR) the solution is available in closed form; in all other cases it is found iteratively. Both routes give the same value.

For mixtures, a and b are the mixture parameters given by the mixing rule of the cubic (van der Waals one-fluid rules by default), so the composition dependence of the scale factors, and the effect of the binary interaction parameters kᵢⱼ and lᵢⱼ, come entirely from the cubic. The scaling model supplies only the mapping; the accuracy of the final Helmholtz energy comes from the reference equation.

Notes

  • If the fluid of interest is the reference fluid, and both cubics use the same parameters, f = h = 1 and the reference equation is recovered unchanged.
  • The two cubics must be the same equation because equality of Γ and β implies equal Helmholtz energy only if both fluids obey the same functional form (same δ₁, δ₂, α(T) and mixing rule).

Using different cubic equations for the fluid of interest and the reference fluid is not currently supported.

References

  1. Mollerup, J. (1998). Unification of the two-parameter equation of state and the principle of corresponding states. Fluid Phase Equilibria, 148(1–2), 1–19. doi:10.1016/s0378-3812(98)00230-1
  2. Michelsen, M. L., & Mollerup, J. M. (2007). Thermodynamic Models: Fundamentals and Computational Aspects, 2nd ed. Tie-Line Publications.

Clapeyron.SPUNG — Function
SPUNG(components;
reference_model = PropaneRef(),
shape_model = SRK,
shaperef_model = shape_model,
idealmodel = BasicIdeal,
reference_component = only(Clapeyron.component_list(reference_model)),
ideal_userlocations = String[],
shape_userlocations = String[],
shaperef_userlocations = String[],
verbose = false,
reference_state = nothing)

Input models

  • reference_model: accurate pure-fluid equation of state (normally a multiparameter Helmholtz equation) used as athe reference model. It must be already created.
  • shape_model: cubic equation of state that defines the mapping between the fluid of interest and the reference fluid (for example SRK or PR).
  • shaperef_model: cubic equation that represents the reference fluid in the mapping. Default: the same as shape_model. It must be the same model type as shape_model. It is created with components equal to reference_component.

Description

SPUNG: State Research Program for Utilization of Natural Gas

ECS method. The residual Helmholtz energy of a pure fluid or mixture is taken from a very accurate equation of state for a pure reference fluid, evaluated at a corresponding state:

Aʳᵉˢ(T,v,x)/RT = Aʳᵉˢ₀(T₀,v₀)/R₀T₀        T₀ = T/f ,  v₀ = v/h

The scale factors f and h depend on temperature and composition, and are calculated from a cubic equation of state (by default SRK) with the SPUNGScaling model: h is the ratio of the covolumes b/b₀, and f follows from equating a(T)/(bRT) for the fluid of interest and for the reference fluid. In mixtures the parameters a and b come from the cubic's mixing rules. If the reference equation is itself the same cubic, SPUNG reduces to that cubic.

The ideal-gas part is independent of the scaling and is given by idealmodel.

Model Construction Examples

# Default: SRK shape equation, propane reference fluid
model = SPUNG(["methane","carbon dioxide"])

# Another reference fluid (any pure-fluid Helmholtz equation)
model = SPUNG(["carbon dioxide","nitrogen"], reference_model = SingleFluid("methane"))

# Another shape equation (used for the mixture and for the reference fluid)
model = SPUNG(["methane","ethane"], shape_model = PR)

# Realistic ideal-gas heat capacities, for caloric properties
model = SPUNG(["methane","ethane"], idealmodel = ReidIdeal)

# Custom parameters (e.g. SPUNG-specific interaction parameters) for the mixture's cubic
model = SPUNG(["methane","ethane"], shape_userlocations = ["path/to/my/db"])

  2. Michelsen, M. L., & Mollerup, J. M. (2007). Thermodynamic Models: Fundamentals and Computational Aspects, 2nd ed. Tie-Line Publications.
